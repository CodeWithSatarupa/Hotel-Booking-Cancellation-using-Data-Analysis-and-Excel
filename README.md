# 🏨 Hotel Booking Cancellations – Excel Dashboard (Beginner Project)

## 📌 Project Overview

This is a beginner-level data analysis project where I’ve created an interactive Excel dashboard to explore hotel booking cancellation patterns. The goal was to practice working with real-world datasets and build insights using Excel tools.

The dataset used was sourced from [Kaggle](https://www.kaggle.com/) and contains detailed information about hotel bookings, including cancellation status, room preferences, booking channels, and more.

## 🎯 Objectives

- Practice data cleaning and analysis in Excel
- Visualize booking and cancellation trends
- Explore patterns across:
  - Hotel types (e.g., Resort, City)
  - Desired vs. non-desired room assignments
  - Lead time and booking distribution
  - Total bookings vs. cancellations
  - Cancellations by deposit type, customer type, etc.

## 📊 Dashboard Features

- Interactive filters (slicers) for exploring different booking categories
- KPIs showing total bookings, total cancellations, and cancellation rate
- Charts for:
  - Cancellation rate by hotel type
  - Room assignment comparison (desired vs. undesired)
  - Booking trends over time
- Clean layout for easy interpretation

## 🛠️ Tools & Skills Used

- Microsoft Excel
  - PivotTables
  - Charts (bar, line, pie)
  - Slicers & filters
  - Basic data cleaning
- Data visualization principles

## 🚀 How to Use

1. Open the Excel file
2. Use slicers to filter by hotel type, customer segment, deposit type, etc.
3. View the updated metrics and charts based on your selections
